# Callaway's 5-Step Script Writing Framework

Source: Callaway YouTube video on script writing (1B+ views, 1M followers).
Synthesised from full transcript (2026-06-03).

This sits alongside the Kyle/Iman state/cost/application/rule framework as a parallel reference. Use whichever fits the script — they don't conflict, they layer.

---

## Step 0 — The Master Principle: Expectations vs Reality

Every script decision flows from this. **Reality must beat expectations.** When reality > expectations: viewer happy, watches, you win. When expectations > reality: viewer disappointed, drops off, you lose. This is the "black magic" that makes everything else work.

## Step 1 — Packaging (Click Confirmation)

- Idea + title + thumbnail
- **Title MUST be locked before writing.** Thumbnail can be loose.
- First few lines of intro must **click-confirm** (mirror the title) and **beat it** (exceed the expectation).
- Example (Mr Beast): title "I spent 100 hours inside the pyramids" → intro shows the pyramids (confirm) + "unprecedented access" (exceed).

## Step 2 — Outline (BEFORE the intro)

- Bullet list of body points FIRST.
- Why before intro: real value is having UNIQUE points; if points aren't unique, no script will save the video.
- Test each point: is it NOVEL? Or is it regurgitated common knowledge? If common, go research more.
- Sources of uniqueness: the tip, the distillation, how you phrase it, the example used.
- For each bullet, layer: **WHAT** (what it is), **WHY** (why it matters), **HOW** (how it fits the puzzle).

## Step 3 — Intro (5-Part Formula)

1. **Immediate context** — bluntly state what the video is about (click confirm).
2. **Establish common belief** — restate the conventional take so viewer feels seen.
3. **Contrarian take** — contradict the common belief (creates expectation vs reality contrast).
4. **Plan** — ordered list of what's coming.
5. **Proof** — credibility (numbers, results, authority).

Parts 4 + 5 can swap order.

## Step 4 — Body (2-1-3-4 Method)

**Order points by value, NOT in numerical order:**
- 2nd best → SLOT 1
- BEST → SLOT 2
- 3rd best → SLOT 3
- 4th best → SLOT 4

**Why:** human brains work in patterns. If slot 1 = good and slot 2 = better, the viewer's brain assumes value will keep escalating, so they stay. If slot 1 = best, every subsequent point feels like a drop and they leave.

**Music album analogy:** best track is usually #3 or #4, not #1. The single comes AFTER the intro track because the value-escalation pattern keeps the listener through the whole album.

### The Value Loop (per body point)

Each body point uses **3 beats**:
1. **Context** — what it is, explained simply
2. **Application** — how to do it + concrete examples
3. **Framing** — why this matters + how it fits the bigger puzzle

### The Wave Rhythm

Constant zoom-in (tactics) → zoom-out (big picture) → zoom-in → zoom-out. Adds comprehension; viewer gets both the strategic frame and the immediate-action tactic.

### Rehooking Between Points

Mini-hooks at every body-point boundary. Examples:
- *"That point was important, but if you don't also couple it with this next one, the magic is lost."*
- *"That's the first piece. The second piece is the one that makes the first piece actually work."*

Brains are on attention delay. Without rehooking, interest decays and the viewer bounces.

## Step 5 — Outro (Fortune Cookie)

- Summarise the points + remind them of the pain-point solved.
- High note = lasting impression.
- This is where likes / comments / shares / rewatches happen.
- "Free chocolate after the meal" — leave them remembering.

## Bonus — CTA Integration (Native Embedding)

Don't break flow with ads. Instead:
- **Frame the pain point first**, then offer your resource as the solve.
- Or **speedrun a framework so fast** that your free resource is positioned as the compress/recap.
- The CTA shouldn't feel inserted — it should feel like the natural next sentence.

## How Callaway sits alongside the existing Kyle/Iman framework

| Layer | Kyle/Iman (existing skill) | Callaway (new) |
|---|---|---|
| **Body-point internal structure** | STATE → COST → APPLICATION → RULE | Value Loop: Context → Application → Framing |
| **Body-point order** | Doesn't prescribe | 2-1-3-4 method (2nd best first, best second) |
| **Intro structure** | Boring Intro System (3 lines, 8s, mirror title, exceed) | 5-part formula (context → common belief → contrarian → plan → proof) |
| **Between-point transitions** | Subtle reveal of next thing they understand | Rehooking with mini-hooks |
| **CTA integration** | Mid-section + end | Native embeds (pain frame → solve) |
| **Outro** | Recap + identity-shift + next-video CTA | Fortune cookie — leave on high note |

Both frameworks are compatible. The cleanest synthesis:
- Use Callaway's 2-1-3-4 ordering for body points
- Use Kyle's STATE/COST/APPLICATION/RULE OR Callaway's Value Loop within each point (whichever fits the point's content)
- Use Callaway's 5-part intro formula
- Use Callaway's rehooking principle between points
- Use Kyle/Lauren's banned-language sweep on the final pass
